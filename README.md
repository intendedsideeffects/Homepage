# Intended Side Effects

A personal portfolio exploring the intersection of data, design, and visual storytelling, centering human and more-than-human experiences.

The website features an interactive particle visualization built with D3.js, where visitors can leave colorful traces through their interactions.

Built with HTML, CSS, JavaScript, and D3.js.

To run locally, open a terminal in this folder and run `py -m http.server 3000`, then visit `http://localhost:3000/`.
