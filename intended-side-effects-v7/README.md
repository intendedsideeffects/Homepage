# Intended Side Effects — v7

Simple static portfolio with HTML, CSS, D3.js v7 and SVG. No npm or Canvas.

Start from this folder:

```powershell
py -m http.server 3000
```

Open http://localhost:3000 and refresh with Ctrl+Shift+R after replacing files.

The About, Projects and Contact sections share one `.section` layout and heading style. Customize the particle motion with `SETTINGS` in `script.js`.
