# Intended Side Effects — D3 Portfolio Hero

A minimal, responsive portfolio landing page with a D3.js particle network and light/dark theme.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` using the **Live Server** extension, or run `python -m http.server 8000` and visit http://localhost:8000.
3. Internet access is required for the D3.js CDN and Google Fonts.

## Customize

- `index.html`: headline, intro text, navigation and sections.
- `style.css`: typography, spacing and theme colors.
- `script.js`: D3 node clusters, connections, pointer interaction, theme toggle.

Replace `hello@example.com` with your real contact email before publishing. The About and Projects sections are placeholders.
